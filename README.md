# Даниил

Инженер ПТО в строительстве. Строю ИИ-агентов, которые берут на себя рутину
инженера: документы, графики, тендеры, поиск по нормативке. Всё, что можно,
держу локально — на своём железе, без облака.

## Чем занимаюсь

- **Свои ИИ-агенты на рабочем ПК** — Claude Code, субагенты под профильные
  задачи (документы, графики, право и нормативка), MCP-серверы, RAG по
  нормативной базе.
- **Локальная обработка речи и памяти** — расшифровка на своей видеокарте,
  разбор локальной моделью, память в обычных файлах, доступная любому агенту.
- **Железо и прошивки** — свой носимый диктофон-компаньон на nRF52840,
  корпус под 3D-печать, клиент на Android.
- **Параметрический CAD для ИИ** — агент проектирует печатные детали кодом,
  а не генерирует сетки.

## Принципы

- Данные пользователя остаются у пользователя.
- Честно пишу, что не проверено, — с цифрами, а не «стало лучше».
- Код без прогона тестов не считается готовым.
